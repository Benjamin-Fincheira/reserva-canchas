# SportsReserve
## Descripción
SportsReserve es una aplicación web interactiva desarrollada para la gestión y reserva de canchas deportivas. La plataforma permite a los usuarios buscar instalaciones por disciplina y precio, consultar la disponibilidad de horarios en tiempo real por fecha y administrar sus reservas mediante un carrito de compras dinámico.

## Funcionalidades Principales
- Búsqueda y filtrado de canchas por deporte, nombre y rango de precio por hora.
- Visualización de detalles de cada cancha (capacidad, superficie y precio).
- Calendario dinámico para consultar disponibilidad en los próximos 10 días.
- Bloqueo de horarios en tiempo real para evitar reservas duplicadas.
- Carrito de compras con resumen de reservas, costo total y opción para eliminar elementos.
- Persistencia de datos mediante almacenamiento local (localStorage) para mantener el estado de las reservas confirmadas.

## Tecnologías Utilizadas

## Instrucciones de Ejecución

1. Clonar el repositorio:
git clone https://github.com/Benjamin-Fincheira/reserva-canchas.git

2. Acceder al directorio del proyecto:
cd reserva-canchas

3. Instalar las dependencias necesarias:
npm install

4. Iniciar el servidor de desarrollo local:
npm run dev
